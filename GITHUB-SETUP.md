# GitHub organization setup

## Organization

- Description: **Ready-made local AI infrastructure for embeddings, vision, voice, and inference.**
- Website: **https://impossibleg.org**
- Avatar: `profile/assets/impossible-g-avatar.png`
- Public profile repository: `impossibleG/.github`

Pin these repositories in this order:

1. `impossible-embeddings`
2. `impossible-ocr`
3. `impossible-voice`
4. `impossible-inference`

## Repository metadata

Descriptions and topics are stored in `brand/manifest.json`. Set **https://impossibleg.org** as the homepage for all four repositories.

Each repository receives `docs/assets/social-preview.png`. Upload that file under **Settings → General → Social preview** after its commit is available on GitHub.

## Public members

Members who should appear on the organization page and Impossible G website must set their organization membership to public in GitHub.
